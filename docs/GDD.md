# GDD v1.0
전 연령, 웹 우선 PWA 후 앱 확장. 일반 모드 시간 기록만, 도전 스테이지별 시간과 오답 5초 차감. 쉬움 5/보통 6/어려움 7개. 양쪽 입력 및 원형 마커, 동기 줌/이동. 무료 힌트 1회, 추가 보유 힌트, 무작위 미발견 영역 3초 강조. 반복 정답 무페널티. 도전 실패 시 최대 1회 코인 이어하기 또는 일반 전환; 랭킹 이어하기 금지. 점수는 개별 난이도·클리어·정확도·무힌트·도전 잔여시간; 직접 감점 없음. 별 1~3성 오답/힌트 기준, 모드별 최고 별 저장, 해금에는 높은 값만 합산. 챕터 순차 해금, 누적 별 조건, 자유 선택은 해금 스테이지. 최초/최고/최근 기록. 일반 중단 복원, 도전 중단 복원 없음. 최초 3챕터 30스테이지(일상/자연/신화와 환상), 별도 튜토리얼. 챕터 내 난이도 상승. 장기 기능: 코인·힌트·레벨·EXP·칭호·아바타·프레임·테마, 컬렉션 최초 클리어 등록/확대/즐겨찾기/완성 보상, 누적 출석, 일일/주간/누적 미션, 업적, 복귀 및 시즌 보상. 무료 코인 소비는 힌트·이어하기·꾸미기, 반복 보상 축소 및 일일 상한. 광고/결제/유저 계정 제외. 수치 및 보상 밸런스는 테스트 후 확정.
