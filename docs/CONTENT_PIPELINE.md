# Content pipeline
기본 동화풍, 챕터 내 일관성, 테마 확장. 1:1 기본, 2048 PNG 마스터, WebP/AVIF 서비스 파생본 환경 최적화. AI/직접/라이선스 원본, 교체 가능한 모델 어댑터. AI 변형 추천→제작자 승인→영역별 독립 편집→합성(마스크 외 원본 복원)→픽셀 차이/히트맵→좌표 자동 추출/수동 승인→난이도 산정→검수/테스트→배포. 9종 변형(추가/삭제/색/크기/위치/회전/형태/디테일/수량), 유형 최대 2개, 같은 사물 복합은 1정답. 난이도 혼합, 크기 상하한, 밀집 방지. 0~1 좌표, 원/사각/다각형, 양쪽별 hitbox 동일 ID, 가변 허용 범위에도 중첩 금지. 미세 색 차이 및 미등록 식별 차이 금지. 접근성/연령/저작권 검수. 버전 고정/롤백, 즉시/예약/기간 공개, 오류 신고. 우선순위/재시도/취소/동시성/비용 한도 워커. 제작자/검수자/운영자/최고관리자. 공개 저장소에는 서비스 이미지, 비공개 제작 저장소에는 마스터·마스크·정답·프롬프트·라이선스. 무료 환경 우선, 유료 API 별도 승인.
