# PRD
MVP: 핵심 플레이, 챕터/해금, 기록, 기본 Studio(등록·정답 편집·테스트·배포), 일일 글로벌 랭킹. 3챕터 30개 + 별도 튜토리얼. 난이도별 검증 이미지 1쌍 먼저. 사용자 로그인 없음; 닉네임은 첫 랭킹 등록 시, 중복 허용 번호 표시, 변경 간격 제한. 로컬 초기화 및 JSON 백업/복원(공식 랭킹 제외). 공식 도전 모든 재도전 허용, 일일 최고 및 시즌 누적 별도, KST 자정, 검증된 클리어만, 동점은 시간/오답/힌트/최초 달성 시각. 무료 힌트 1회만, 타이머 지속, 이어하기 없음. 개인정보 최소 처리, 추적 광고 없음, 로그 보관 제한. 관리자만 관리형 인증/RBAC. 후속 성장·AI 자동화·PWA는 로드맵에 따름.
