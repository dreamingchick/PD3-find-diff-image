# API 초안
GET /chapters, GET /stages/:id (공개 메타만); POST /sessions (버전 고정), POST /sessions/:id/ready, POST /sessions/:id/input (side,x,y,eventId), POST /sessions/:id/hint, POST /sessions/:id/continue, POST /sessions/:id/finish. GET /daily, GET /leaderboard/daily, GET /leaderboard/season, POST /leaderboard/register (검증 세션 및 닉네임), PATCH /nickname. 서버 시간/좌표/상태/중복 입력 검증. 관리자 API는 별도 권한 확인. 정답 미발견 좌표는 반환하지 않음. PostgreSQL 후보 테이블: stage_versions, differences, image_assets, game_sessions, game_events, anonymous_tokens, daily_challenges, leaderboard_entries, quality_reviews, admin_audit_logs. 최종 스키마와 요청 계약은 구현 시 테스트로 확정.
